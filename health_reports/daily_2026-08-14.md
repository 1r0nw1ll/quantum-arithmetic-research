- `qa_detect/examples/bench_odds_variant_B.py` → `qa_detect/examples/benchmark_protocol.json`

**Fix:** Install `scikit-learn` in the execution environment, or add a `# noqa: BENCH-1` comment to these scripts if they are intentionally run in environments without sklearn.
